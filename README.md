# HR Analytics Dashboard – Excel

## Project Overview
This project focuses on analyzing employee data using Microsoft Excel to generate meaningful HR insights and support data-driven decision-making.

## Tools & Technologies
- Microsoft Excel
- Power Query (if used)
- Power Pivot
- Pivot Tables
- DAX Measures
- Interactive Slicers
- Excel Charts

## Key Performance Indicators (KPIs)
- Total Employees
- Active Employees
- Inactive Employees
- Attrition Rate
- Average Salary
- Average Age

## Key Analysis
- Department-wise Attrition Rate
- Job Title-wise Attrition Rate
- City-wise Attrition Analysis
- Employee Distribution by City
- Completed Projects by Employee
- Average Salary by Department
## Key Insights
- Identified departments with higher employee attrition.
- Compared employee distribution across different cities.
- Analyzed employee project completion.
- Evaluated workforce distribution and salary patterns.

## Dashboard Features
- Interactive slicers
- Dynamic KPI cards
- Pivot Table-based analysis
- Visual HR dashboard

## Objective
To transform raw employee data into meaningful insights that help understand workforce distribution, employee performance, and retention patterns.
